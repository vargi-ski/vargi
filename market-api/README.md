# VARGI Market API

Backend барахолки стаи ВАРГИ.

## Отправка и проверка

- `npm ci && npm test` — изолированные регрессионные тесты без боевых секретов и Telegram-отправок.
- `/submit`: до 6 фото по 8 МиБ, суммарно до 24 МиБ; JPEG/PNG/WebP до 64 Мп, преобразование в JPEG до 1800 px. Фронтенд принимает исходники до 15 МиБ и уменьшает их перед отправкой; HEIC до 8 МиБ.
- Сервер проверяет обязательные поля и согласие `board-submit-2026-10-05`. Категория, контакт и форматированная цена формируются из проверенных значений.
- UUID `requestId` + хеш содержимого записываются вместе с заявкой. Повтор возвращает прежний ID, изменённое содержимое с тем же ключом — 409. Конкурентная блокировка рассчитана на текущую одну реплику сервиса; перед масштабированием нужен общий атомарный механизм.
- Тайм-аут браузерной отправки — 120 секунд. При ошибке форма и фото остаются во вкладке, повтор использует прежний ключ. Лимит 6 попыток за 15 минут сохраняется; 429 содержит `retryAfter`.
- `telegram_notify_sent id=…` подтверждает принятие уведомления Telegram API; это не подтверждение прочтения человеком. Заявка сохраняется независимо от доступности Telegram.

## Хранение

- заявки и фотографии: постоянный Railway volume `/data/submissions`;
- хеш пароля администратора: `/data/admin-auth.json`;
- удалённые объявления сначала попадают в статус `trash` и физически очищаются через 30 дней.

## Резервные копии

Сервис создаёт ежедневный архив volume-данных в приватный Railway Bucket и хранит последние 14 дней.
Ручной backup доступен из админ-панели.

Переменные:
- `BACKUP_S3_ENDPOINT`
- `BACKUP_S3_REGION`
- `BACKUP_S3_BUCKET`
- `BACKUP_S3_ACCESS_KEY_ID`
- `BACKUP_S3_SECRET_ACCESS_KEY`

## Администратор

- `ADMIN_SESSION_SECRET=[secret]`
- `ADMIN_RECOVERY_TOKEN=[secret]`
- `ADMIN_SETUP_TOKEN` используется только при первичной инициализации и после неё должен быть удалён.
