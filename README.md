# vargi

## Редакционные правила

- Имя основателя: **Артем Грязев** — через «е», включая склонения, метаданные и тексты заявок.
- ВАРГИ — **стая**. Использовать это обозначение в меню, текстах, подписях и формах.
- Текстовый логотип в шапках и подвалах: «А» и «Г» — ледяно-синие (#8fd0ef), остальные буквы — белые. Использовать общий `/assets/brand-wordmark.css` и обёртку `.vargi-wordmark`, чтобы буквы не раздвигались в flex-контейнере.
- В блоке партнёров Easy Nutrition используется официальный логотип: https://easynutrition.ru/img/logo.svg. Ссылка на каталог сохраняется с фильтрами, заданными владельцем сайта.

## Магазин

- Главная: компактная витрина четырёх категорий, без полного списка товаров.
- `/shop/`: каталог с фильтрами; `?category=racing` открывает категорию, `?product=race-suit` — подробную карточку. Кнопка «Назад» и Escape закрывают карточку.
- В каталоге сразу под фотографиями видны полные описания, состав, размеры с остатками и сроки предзаказа. Закончившиеся товары остаются в каталоге с явным статусом; будущий выпуск не обозначать как распроданный.
- `/assets/shop-catalog.js`: единый источник названий, описаний, цен, размеров, предзаказов и категорий для витрины, каталога и формы заказа.
- `/shop/order/`: оформление заявки; наличие, доставка и оплата согласуются отдельно. Не подменять плановую дату выпуска гарантированной датой доставки.
